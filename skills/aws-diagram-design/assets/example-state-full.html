Golden AMI lifecycle

The four states a golden AMI passes through from build to deprecation, with the failed-test loop made explicit. Available is the state the platform team optimizes for — hence orange.

THE HEADLINE

Available is the win state

Everything flows toward Available. The rebuild loop is dashed because it's a detour, not a failure — the Image Builder pipeline simply runs again.

Fail is a loop, not a dead-end

  • Dashed to signal detour
  • Returns to Building, not a new state
  • Test report is the action

Deprecation keeps launches

A deprecated AMI drops out of DescribeImages for the accounts it is shared with (the owner still sees it), but Auto Scaling groups that pin its ID keep launching. Only Delete deregisters the image and its snapshots.
