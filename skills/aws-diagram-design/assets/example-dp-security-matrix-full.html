AWS data platform access matrix

A compact policy view for five IAM roles across Amazon S3, Athena, SageMaker AI, Quick Sight, and MWAA. Each intersection resolves to one explicit IAM or Lake Formation permission level.

THE HEADLINE

Partner access stops at Quick Sight

The partner role reads embedded Quick Sight dashboards only. It cannot reach S3 buckets, SageMaker AI notebooks, or MWAA environments.

Administration stays separate

  • Administrators hold admin rights everywhere.
  • Engineers write across the platform.
  • Scientists write only in SageMaker AI.

Analyst scope is narrow

Analysts query Lake Formation-governed tables in Athena and author Quick Sight content, while S3, SageMaker AI, and MWAA remain unavailable.
