AWS sign-up to first bill: the first month

One persona, five stages from account sign-up to cost guardrails. The sentiment curve is the point: a confident start, a dip when the first bill shows NAT gateway charges nobody budgeted for, and a recovery once AWS Budgets alerts are in place.

TROUGH

First bill

The NAT gateway charges arrive with no budget alert configured, and Cost Explorer trails the spend by about a day. This is the one stage worth fixing before anything else.

Recovery, not just relief

Sentiment climbs back to neutral once guardrails are set rather than back to high — the surprise is remembered. Track this cohort's 90-day retention separately from builders who set budgets on day one.

Early signal

Create account and first deploy both read high. The console and CDK first impression is working; the problem is entirely cost visibility.
