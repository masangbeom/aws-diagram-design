AWS analytics platform integration topology

AppFlow, DMS change data capture, and Kinesis land in Amazon S3, Athena serves three consumer services, and IAM Identity Center and CloudWatch remain visibly cross-cutting.

THE HEADLINE

S3 and Athena are the platform core

Amazon S3 holds durable Iceberg tables; Athena provides governed, serverless SQL access without hiding the wire protocols.

Every integration stays explicit

  • Salesforce arrives via AppFlow over REST
  • Aurora orders arrive as DMS CDC
  • Consumers use JDBC, kernels, or HTTPS

Services apply to the whole layer

IAM Identity Center and CloudWatch terminate at the platform boundary, not at an individual component.
