THE HEADLINE

DynamoDB is not in the subnet

DynamoDB and Secrets Manager are Regional services, not VPC tenants. Packets reach them through interface endpoints in the shared subnet, not because the table sits behind that subnet's security groups.

What sits where

  • Checkout API on Fargate in subnet-app
  • Interface endpoints in subnet-ep
  • App and shared VPCs joined by peering

Two shapes, two meanings

Dashed rx=4 bands are the account and Region. Solid rx=8 boxes are VPCs and subnets. Greyscale still has to tell them apart.
