FOCAL · API GATEWAY

API Gateway drives 55% of invocations

75% growth over 8 weeks — from 120M to 210M invocations. Two public REST endpoints moved off ECS in W4 and account for the step change. The W5 dip is a regional holiday in the main market.

SQS: stable core

22% growth (80M→98M) — this is the order-processing queue draining at a steady batch size. The near-flat slope is a healthy baseline, not stagnation. Back-end work scales with orders, not with API traffic.

EventBridge: early signal

67% growth (45M→75M), driven by one partner SaaS event bus. Volatile week-to-week but directionally positive. Worth a concurrency review before more rules fan out to the same functions.
