Venn · AWS Diagram Design

AWS app stack · Serverless × Containers × Managed data

Three traits a workload can pick up on AWS. Each one hands an operational burden to AWS; only the center hands over all three. Orange marks the intersection worth designing toward.

THE HEADLINE

One fully managed center

Three overlapping circles create seven regions. Six of them are diagnostic — they name what is still on you. Only the center earns the orange. If every region is colored, the diagram stops prioritizing anything.

The three tests

  • Serverless — Lambda or Fargate, no hosts to patch
  • Containers — images in Amazon ECR, run on ECS or EKS
  • Managed data — Aurora, DynamoDB, ElastiCache
  • All three — ECS on Fargate with Aurora Serverless v2

The partial stacks

Lambda with DynamoDB (serverless, managed data; a container image is optional, not the unit you run). EKS on EC2 with Aurora (containers, managed data, nodes to patch). Fargate with a self-run database (serverless containers, DB on you). Naming each one makes the map more useful than the center alone.
