Generative AI assistant on AWS · Wardley map

The AWS value chain behind a generative AI assistant, from the user-facing need down to raw infrastructure, positioned against how evolved each component is. The one arrow is the map's point: agent orchestration is commoditising, so betting engineering time on a bespoke orchestrator is a shrinking advantage.

MOVEMENT

Agent orchestration

Still custom-built today, but managed runtimes such as Amazon Bedrock AgentCore push it toward product. Betting differentiation here has a shrinking half-life.

Eval harness

Genesis-stage and specific to this product's failure modes. No off-the-shelf harness captures what "good" means for this assistant yet — worth the custom build.

EC2 GPUs · Amazon S3

Fully commoditised. Rent capacity on demand — any engineering time spent here is time not spent on the parts of the chain that are still genesis or custom-built.
